# Verification and Claim Boundaries

## Current Evidence

Placeholder packaging/compilation, formatting, metadata and documentation/ignore checks have run.
They establish a minimal distributable crate and authoring boundaries, not inference, numerical
quality, OpenCode compatibility or Apple GPU performance. No native capability spike, model
inference or physical-hardware acceptance benchmark is recorded.

## Evidence Layers

| Layer | Establishes | Cannot establish |
| --- | --- | --- |
| Documentation/manifest checks | Links, identities, catalogs and package boundaries | Runtime semantics or speed |
| Deterministic fake-backend tests | Rust transitions, reservations and HTTP encoding | Metal lifetimes, allocations or numerics |
| Native spikes | Actual sharing, geometry, controls, safe failure/unload | Complete agent quality or product leadership |
| Pinned-client interoperability | Released client streams and tool-result behavior | Every client/version |
| Numerical/coding suites | Declared reference/tolerances and bounded task quality | Universal coding ability |
| Physical-host acceptance | Spec metrics on recorded M4 Pro conditions | Other machines/workloads |
| Optimized competitor matrix | Scoped relative performance at matched quality/resources | Universal or indefinite market leadership |

## KPI Ownership

[Feature success criteria](../specs/001-agent-runtime/spec.md#success-criteria-mandatory) own
thresholds; the [protocol](../specs/001-agent-runtime/benchmark-protocol.md) owns clocks, cohorts,
memory attribution and statistics; the [catalog](../specs/001-agent-runtime/contracts/qualification.md)
owns case identities. Do not copy mutable acceptance numbers here.

Evaluate useful-output latency, loop time, overhead, cancellation, memory, state correctness,
interoperability, task outcomes and privacy separately. Aggregates cannot hide failures or tradeoffs.

## Gate Disposition

Use pass, fail, blocked or inconclusive. Missing native/hardware evidence means blocked. Retain
failed, cancelled and timed-out runs and uncertain attribution. Compilation, generated tasks,
filled checklists or valid artifact hashes cannot authorize serving/reuse by themselves.
Qualification uses selected reviewed public fixtures; routine diagnostics exclude private content.

The [validation guide](../specs/001-agent-runtime/quickstart.md) marks future commands unimplemented.
Public reproduction must eventually work from clean builds/packages without ignored local files.
